# Cross-check Skill

## Mission
Each agent must review the other agent's candidates before the Orchestrator creates the final report.

## Agent 1 checks Agent 2
Check whether research candidates:
- Really have usable API access
- Are practical for automation
- Can be integrated into Python workflow
- Have hidden costs or rate-limit risks

## Agent 2 checks Agent 1
Check whether coding candidates:
- Have credible evidence
- Are better than current stack
- Are suitable for real coding and analysis
- Have hallucination or stability risks

## Output
For each candidate:
- Confirmed facts
- Unclear facts
- Red flags
- Recommendation: KEEP / TEST / REJECT
