# Final Evaluator Skill

## Mission
Turn agent findings into a clear human-readable decision report.

## Decision Types
1. KEEP CURRENT
2. TEST NEW MODEL
3. REPLACE AFTER APPROVAL
4. REJECT CANDIDATE

## Rule
Never recommend immediate replacement without human approval.

## Final Report Sections
- Executive Summary
- Current Model
- New Candidates
- Comparison Table
- Top Recommendation
- Why Better
- Weaknesses
- Migration Plan
- Human Approval Request
