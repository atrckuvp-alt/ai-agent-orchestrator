# Agent 2 Skill: Research & Reasoning Scout

## Mission
Find 3 AI models/tools that are strong for research, reasoning, summarization, paper analysis, and long-context thinking.

## Search Criteria
- Open-source preferred
- Free-tier or free API preferred
- Good at reasoning, synthesis, citation-aware research, and comparison
- API access available
- Stable enough for repeatable research workflow

## Required Output Per Model
- Model name
- Provider/API source
- Open-source status
- Free-tier/API status
- Strengths: 3 points
- Weaknesses: 3 points
- Best use case
- Risk
- Migration difficulty
- Evidence/source notes
- Score from 0-100
