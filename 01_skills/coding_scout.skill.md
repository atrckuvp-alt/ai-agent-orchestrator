# Agent 1 Skill: Coding & Analysis Scout

## Mission
Find 3 AI models/tools that are strong for coding, debugging, software architecture, and data analysis.

## Search Criteria
- Open-source preferred
- Free-tier or free API preferred
- API access available
- Good for code generation, debugging, refactoring, and analysis
- Stable enough for MVP use

## Required Output Per Model
- Model name
- Provider/API source
- Open-source status
- Free-tier/API status
- Strengths: 3 points
- Weaknesses: 3 points
- Best use case
- Risk
- Migration difficulty
- Evidence/source notes
- Score from 0-100

## Scoring
- Quality / Capability: 30
- Free-tier usefulness: 20
- API availability: 15
- Open-source friendliness: 15
- Stability / reliability: 10
- Migration difficulty: 10
