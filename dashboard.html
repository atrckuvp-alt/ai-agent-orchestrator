AI Agent Research Team Dashboard

How to Use

Open JSON files in 00_memory to inspect system status.

Important Files

  • current_stack.json — active approved models
  • champion_models.json — current best candidates
  • approval_queue.json — pending human approvals
  • decision_history.json — system decisions
  • benchmark_history.json — model test history
  • self_improvement_log.json — improvement ideas

Run Command

python 04_scripts\run_orchestrator.py --api openrouter

Approval Command

python 04_scripts\human_approval.py --request-id REQUEST_ID --decision APPROVE
